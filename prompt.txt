  一、支持的客户端总览

  目标：
  帮助用户根据使用场景选择接入方式，并跳转到对应的详细配置文档。

  实施要求：
  - 按以下类别组织：
    - 命令行与编码代理
    - 官方 SDK
    - OpenAI 兼容客户端
    - 直接 HTTP 请求
  - 至少覆盖当前已经核对过的接入路径：
    - Codex 原生配置
    - Codex++
    - CC Switch
    - OpenAI JavaScript SDK
    - OpenAI Python SDK
    - Shell / cURL
  - 对每种路径说明：
    - 适用场景
    - 配置入口
    - 使用的协议或 API
    - 是否需要自定义 Base URL
    - 模型名从哪里获取
    - 密钥如何提供
  - 明确 Codex++、CC Switch 等属于独立第三方开源工具，不由 Partokens 维护
  - 不把“支持自定义 OpenAI Base URL”直接等同于“已由 Partokens 完整验证”
  - 不列出没有通过当前官方文档或仓库核对的客户端
  - 不提供未经验证的下载链接、provider 名称或配置字段
  - 为已有的 Codex、SDK、API 基础文档提供清晰的内部导航关系
  - 无法确认的客户端兼容性标记为“待实际客户端验证”

  二、模型与定价

  已确认边界：
  - 可用模型和价格属于账户实时配置
  - 文档不能维护可能过期的固定模型清单或固定价格表
  - design-lab 中的模型价格、余额和请求记录是设计样例
  - 设计样例不代表真实账户数据或价格承诺

  实施要求：
  - 从 new-api 核对当前模型计费可能涉及的单位、倍率和结算字段
  - 只描述 Partokens 已启用或账户界面实际展示的计费能力
  - 解释以下概念之间的关系：
    - 模型 ID
    - 模型能力
    - 输入与输出用量
    - 模型价格
    - 账户余额或套餐额度
    - 使用记录中的最终结算
  - 区分：
    - 模型可见
    - 模型可调用
    - 模型支持某个 API
    - 模型有可用路由
  - 提供“选择模型并核对价格”的控制台操作流程
  - 说明不能仅根据模型名称推断：
    - 上下文长度
    - 图像或工具能力
    - 参数支持
    - 价格
    - 可用性
  - 不虚构缓存价格、图像价格、倍率、货币单位或最低收费
  - 不复制 new-api 中 Partokens 未启用的复杂计费能力
  - 明确 design-lab 中的模型价格和用量数据均为设计样例
  - 无法确认的价格字段、计费单位和结算精度标记为“待产品或后端确认”

  三、SDK 配置

  资料来源：
  - 当前 OpenAI 官方 JavaScript SDK 文档
  - 当前 OpenAI 官方 Python SDK 文档
  - 本地 new-api 对 Chat Completions、Responses 和 Models 路由的实际支持

  实施要求：
  - 使用当前有效的 OpenAI SDK 配置格式
  - 分别提供 JavaScript 和 Python 完整示例
  - 包含：
    - 安装命令
    - 环境变量
    - Base URL
    - API 密钥
    - 实时获取模型列表
    - 发送最小聊天请求
    - 读取响应
    - 基础错误处理
  - JavaScript 使用当前官方字段 `baseURL`
  - Python 使用当前官方字段 `base_url`
  - Base URL 统一为：
    https://partokens.com/v1
  - 模型使用占位符，并要求用户从账户或 `/v1/models` 实时选择
  - 根据后端实际支持情况说明 Chat Completions 与 Responses 的选择边界
  - 不假设所有模型同时支持两个 API
  - 不在浏览器前端嵌入长期 API 密钥
  - 不为了让 SDK 在浏览器运行而默认启用危险配置
  - 说明 SDK 自带重试与超时行为时，必须引用当前官方文档；无法确认时不要写死
  - 生成请求超时后可能已被执行，不得建议无条件重试
  - 不固定未经必要验证的 SDK 版本号
  - 不提供未经核对的代理字段、传输选项或实验性参数
  - 配置失败时引导用户使用“连接、限额与重试”文档

    - 成功响应的顶层结构
    - 模型条目的实际字段

  - 提供 Shell、JavaScript、Python 完整示例
  - 示例应：

  - 明确模型出现在列表中不代表：
    - 当前请求一定有可用路由
    - 支持所有 API
    - 支持所有参数
    - 价格固定不变
  - 不根据模型名称猜测能力
  - 不虚构分页、筛选、排序或额外查询参数
  - 如果响应中包含非稳定或后端内部字段，只说明当前可观察行为，不将其写成长期契约
