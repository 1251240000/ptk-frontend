# Partokens R3.1 公共与内容页面原型

状态：页面族完成内部验收，等待产品评审  
评审入口：`http://127.0.0.1:4180/#home`

## 1. 范围

本轮只在 `apps/design-lab` 中实现高保真页面，不修改 `new-api/`、`new-api-docs-v1/`、正式 `apps/web`、正式 `apps/docs` 或 Caddy 发布路由。

已实现：

- 首页：Hero 产品实景、Get started、三组功能实景、六项关键词、FAQ 和联系入口。
- 模型广场：匿名能力边界、真实登录门槛、兼容接口路径。
- 使用文档：基础地址、身份验证、首次 cURL、SDK 切换和参考入口。
- 关于：产品边界、Route Capsule 流程和三项设计原则。
- 法律：用户协议、服务协议和隐私政策的统一阅读模板。
- 通知：仓库随版本发布的通知，不模拟用户消息收件箱。
- 公共壳层：桌面/移动导航、七语言、明暗主题、通知、登录、控制台和页脚。

R1 首页的信息结构已经迁入 R3.1 公共壳层。首页正文、产品实景、主题、导航和七语言现由同一页面族维护，不再保留独立的 R1 首页渲染分支。

## 2. 设计结构

公共页面使用一条连续的模型接入路径组织内容：

```text
Prompt / account intent -> compatible route -> server-authoritative result
```

- `Route Capsule` 只用于确定性主行动。
- Relay Blue 表达路由、焦点、当前项和终点。
- Prompt Lilac、Canvas Mint、Result Coral 只用于能力路径。
- 页段使用连续背景与分隔线；只有登录门槛、代码块和真实工具状态使用框定表面。
- 匿名模型页不展示模型名、价格、倍率、延迟或可用率。

## 3. 内容与国际化

- `@partokens/content` 提供关于、通知和三类法律文档的七语言内容。
- `@partokens/i18n` 提供既有页面与导航词条。
- `public-home-copy.ts` 提供首页简中、繁中、英语、日语、俄语、法语和越南语正文。
- R3.1 新增词条在原型模块内提供简中、繁中、英语、日语、俄语、法语和越南语翻译，待负责人审核后再并入正式资源。
- 切换语言不会改变当前页面；`document.lang` 与选择保持一致。
- 文档代码、端点和 SDK 名称保持原始技术写法。

## 4. 交互与无障碍

- 移动导航打开后聚焦关闭按钮、锁定背景滚动、限制 Tab 循环，Escape 关闭并恢复原焦点。
- 图标按钮均有名称和 tooltip；复制动作使用本地化状态反馈。
- 代码只允许在代码表面内部横向滚动，页面本身不得溢出。
- 法律与文档索引在 820px 以下转换为水平任务导航。
- 深色主题的品牌页脚使用稳定语义 token，不借用会反转的主命令颜色。
- Hero 在 1440、1024、768、390 和 320px 首屏均露出下一段内容；最小宽度下只简化产品预览中的一条演示消息。

## 5. 评审重点

1. 首页是否准确表达“对话、生图、API 接入”三类真实工作，并能立即行动。
2. 模型广场的匿名门槛是否足够可信且不显得空。
3. 文档页的中等密度是否适合长期阅读和复制操作。
4. 关于、法律和通知内容是否适合进入负责人文案审核。
5. Route Capsule、产品实景和工作流色带是否具有足够品牌辨识度。
6. 统一公共壳层是否可以作为 R3.2 认证页面族的基础。
