# Partokens R3.6 生图工作台页面族原型

状态：页面族完成内部验收，等待产品评审  
评审入口：`http://127.0.0.1:4180/#console-studio`

## 1. 范围

本轮只在 `partokens-ui/apps/design-lab` 中实现高保真生图工作台，不修改 `new-api/`、`new-api-docs-v1/`、正式 `apps/web`、Caddy 路由或生产发布配置。

已实现：

- 本地项目的新建、选择、重命名、复制、删除、导入和导出。
- 提示词、参考图、结果和备注节点，以及节点移动、选择、连接、断开和删除。
- 画布平移、缩放、适应视图、撤销和重做。
- 模型、分组、尺寸、数量、质量和背景等生成设置。
- 现有密钥会话解锁、受限专用密钥确认、主动锁定和离开页面清理。
- 模拟生成、取消、失败、重试、结果历史和稳定节点状态。
- IndexedDB 项目/素材存储、本地数据披露、桌面双轨和移动端项目/检查器抽屉。
- 七语言、明暗主题和统一控制台壳层。

本阶段不发送真实 `/v1/images/*` 请求，不复制或引入 `basketikun/infinite-canvas` 的 AGPL 源码。

## 2. 信息结构与视觉模式

```text
控制台侧栏
└── 生图工作台
    ├── 紧凑工具栏
    ├── 本地项目轨
    ├── 无限画布
    │   ├── 参考图节点
    │   ├── 提示词节点
    │   ├── 结果节点
    │   ├── 备注节点
    │   └── 生成路径
    ├── 检查器
    │   ├── 节点属性
    │   ├── 生成设置
    │   ├── 会话密钥
    │   └── 本地历史
    └── 画布 / 密钥 / 模型状态
```

- 页面在全局顶栏下使用完整高度，不把画布缩进普通内容卡片。
- “生成路径”是本页特征结构：参考图、提示词、结果和备注通过可见连接保留创作因果关系；生成中连接使用克制的流动状态。
- 项目轨用于高频切换，检查器承载低频设置；两者在窄屏变为带焦点约束的底部/侧边抽屉，画布始终是主视区。
- 节点尺寸在空闲、生成、完成、失败和取消状态间保持稳定，状态变化不会推动画布布局。
- 结果视觉使用原型内的非生成式图形素材表达构图占位；正式阶段由真实接口返回的图片素材替换。
- 页面复用 R2.1 tokens、基础控件、对话框和 R3 控制台壳层，没有创建新的按钮或输入视觉体系。
- 移动端底部导航固定为概览、游乐场、生图工作台、钱包和菜单。

## 3. 本地数据模型

原型使用独立 Dexie/IndexedDB 数据库 `partokens-design-lab-r36`，正式实现继续使用 `ownerNamespace = user:<id>` 隔离不同账户。

```text
StudioProject
├── id / ownerNamespace / title
├── createdAt / updatedAt / schemaVersion
├── nodes[] / connections[]
├── viewport
├── generation settings
│   └── tokenId / tokenName（不含完整密钥）
└── local history[]

StudioAsset
├── id / projectId / ownerNamespace
├── mimeType / bytes / createdAt
└── blob
```

- 首次打开注入三个示例项目；初始化元数据将“首次使用”和“用户已删除全部项目”分开。
- 刷新时将遗留的 `generating` 节点归一为 `cancelled`，避免没有计时器的永久生成状态。
- 本地图片以 Blob 写入素材表，项目节点只保存素材 ID；切换项目时创建对象 URL，离开后释放。
- 导入会重建项目、节点和连接 ID，改写用户命名空间，并移除无法随 JSON 传输的本地素材引用。
- 删除项目时在同一事务中删除项目及其本地素材。

## 4. 密钥与接口边界

- 正式生图请求使用 `POST /v1/images/generations`；存在参考图且模型支持编辑时使用 `POST /v1/images/edits`。
- 模型、分组和密钥摘要分别来自 `GET /api/user/models?group=`、`GET /api/pricing` 和 `GET /api/token/`。
- 现有密钥通过 `POST /api/token/:id/key` 显式显示；当前服务端不支持密码或 2FA step-up，确认面必须如实说明。
- 用户也可以确认创建一枚额度有限、仅允许当前生图模型的专用密钥。
- 完整密钥只允许保存在模块/组件内存中，不进入 IndexedDB、Zustand persistence、React Query cache、日志、遥测或导出文件。
- 主动锁定、退出登录、离开工作台、页面卸载和冷重载都必须清除完整密钥。
- 原型只保存 `tokenId` 和可显示的 `tokenName`，浏览器检查确认不存在 `sk-*`、Bearer、`apiKey`、`fullKey` 或 secret 内容。
- 正式实现继续复用已经验证的 API client 与 `@partokens/studio` 请求/能力逻辑；R3.6 仅冻结表现层和工作流。

## 5. 关键交互

- 项目新建、切换、重命名、复制和删除在桌面项目轨与移动项目抽屉中均可用；省略号使用显式开关菜单，不依赖悬停。
- 新节点通过边界检测寻找最近空位，不与现有节点直接重叠；移动节点后可撤销和重做。
- “连接节点”进入明确连线状态，再选择目标完成连接；可对选中节点移除所有连线。
- 画布支持拖动平移、滚轮/按钮缩放和适应全部节点；移动初始视图优先展示提示词到结果的生成路径。
- 点击生成时若密钥未解锁，先进入会话密钥确认；密钥就绪后再开始生成。
- 模拟失败会保留稳定结果节点、错误边框、历史和重试入口；取消会终止计时器并写入本地取消记录；重试复用失败节点。
- 新结果按小幅偏移形成有意的版本叠放，而不是完全重合；生成路径同时保留到各版本。
- 所有项目、密钥和破坏性确认对话框支持初始焦点、Tab 循环、Escape、滚动锁定和焦点恢复。

## 6. 正式无限画布策略

- 正式工作台继续采用 `basketikun/infinite-canvas` 的受控 fork，而不是把 AGPL 源码复制进主应用目录。
- fork 需要独立构建边界、上游版本记录、修改清单、版权/许可证声明和对应源代码提供方式。
- Partokens 负责项目、凭据、模型、生成请求、本地存储和产品壳层；fork 负责画布交互，不拥有账户或密钥。
- R3.6 原型的节点/连接/视口数据结构是迁移契约，不要求正式 fork 复用当前原型 DOM 或 CSS。

## 7. 国际化、响应式与无障碍

- 简体中文、繁体中文、英语、日语、俄语、法语和越南语均覆盖工作台核心词条。
- 通用生图词条来自 `@partokens/i18n`；R3.6 独有词条暂存于 `console-studio-copy.ts`，等待负责人审核后合并。
- 1440、1024、768、390 和 320px 均无页面级横向滚动。
- 1280px 以下收起项目轨，1060px 以下收起检查器，820px 以下进入移动控制台壳层和底部导航。
- 法语 390px 与俄语 320px 深色基准已检查长标签、节点、抽屉、底部导航和主操作。
- 图标按钮均有可读名称和 tooltip；颜色之外同时使用文字、图标、边框或状态点表达状态。
- 抽屉和确认面使用统一焦点约束；`prefers-reduced-motion` 会关闭生成路径和进度条的持续动画。

## 8. 评审重点

1. “项目轨 -> 生成路径画布 -> 检查器”的中等密度是否适合持续创作。
2. 参考图、提示词、结果和备注之间的关系是否足够直观。
3. 结果版本叠放与本地历史是否需要改成其他组织方式。
4. 密钥解锁、受限密钥和内存边界披露是否清楚但不过度打断。
5. 移动端将项目和检查器放入抽屉、保持画布为主视区的策略是否确认。
6. 页面族通过评审后，R3 是否可以收尾并进入 R4 表现层重建。
